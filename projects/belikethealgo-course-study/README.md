# BeLikeTheAlgo course study

Isolated workspace for studying **Formación BeLikeTheAlgo Pro — Benjamín Carmona**.

This branch contains only tooling and our own project structure. Raw course videos, audio, screenshots, transcripts and access credentials must not be committed to GitHub.

## Workflow

1. Build a manifest of the authorized MEGA share.
2. Download only the material required for a processing batch.
3. Extract timestamped transcripts, periodic frames and scene-change frames.
4. Separate instructor statements from our interpretation.
5. Convert confirmed rules into a formal backtesting specification.
6. Validate the strategy on historical data only after the rules are frozen.

## Important

The repository is public, so MEGA links/decryption keys and course media are intentionally excluded from the persistent branch state.
